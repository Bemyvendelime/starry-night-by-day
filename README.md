# 낮에도 별은 빛나니까

어두운 방, 흑백 코딩 창의 빨간 알림 하나에서 시작해 어린 나에게 쓰는 편지가 빈센트 반 고흐 「별이 빛나는 밤」으로 이어지는 인터랙티브 웹 작품입니다. 신세계 지식향연 2026 인문학 크리에이티브 공모전 「예술을 바꾼 혁명, 인상주의」 출품작.

- 작품: https://bemyvendelime.github.io/starry-night-by-day/
- 만든 사람: 허대훈
- 그림: Vincent van Gogh, *The Starry Night*, 1889, The Museum of Modern Art. 퍼블릭 도메인 이미지(Google Art Project, Wikimedia Commons).
- 기술: three.js 0.160, 직접 쓴 펜 해칭·수면·붓질 셰이더, WebAudio 합성음. 렌더링 구조는 iamtechartist 「Every Joule」을 참고했습니다.

고치는 법은 [EDITING.md](EDITING.md), 코드 구조는 [STRUCTURE.md](STRUCTURE.md).
