어떻게 만들어지나

고치는 원본은 src/ 폴더입니다. src/ 는 그대로도 돌아가는 웹 페이지(ES 모듈)라서, 고치면서 바로 볼 수 있습니다. build.py 가 이것을 한 파일로 묶어 docs/index.html 을 만들고, GitHub Pages 는 저장소의 main 가지 docs/ 폴더를 그대로 공개합니다. three.js 본체는 CDN(jsdelivr)에서 받고, 3D 모델과 그림은 docs/assets/ 에 같이 올라갑니다.

단계하는 일도구
1. 원본src/js/content/ 의 원고·장면·카메라·분위기 파일, src/js/world·ui·gfx 의 부품아무 편집기, 또는 github.com 의 연필 버튼
2. 묶기src → docs/index.html (+ docs/assets), 아티팩트용 build/starry-letter.htmlpython build.py (esbuild, node 필요)
3. 올리기커밋하고 GitHub 에 푸시python deploy.py "고친 내용"
4. 자동 빌드src/ 가 바뀐 푸시가 오면 GitHub Actions 가 build.py 를 돌려 docs/ 를 다시 커밋.github/workflows/build.yml
5. 공개GitHub Pages 가 docs/ 를 공개 주소로 내보냄1~2분 걸림

제출 PDF

sian/pdf/submission.html 이 원본이고, python pdf/make_pdf.py 로 다시 뽑습니다. 1쪽은 표지·링크·QR·감상 방법, 2쪽은 작품 소개·장면 6컷·인상주의와 잇는 세 가지·만든 방법입니다. 장면 사진은 pdf/img/ 에 있고, 바꾸려면 주소에 ?shot=1#beat-번호 를 붙여 연 화면(아래 막대 없음)을 캡처해 같은 이름으로 넣습니다. QR 은 공개 주소를 가리킵니다.
